# C2: The format's one change

Stage C2 of `plan3.md`: the format and the check change once, before stage D writes two large
models in them. The list is what three runs on two systems of the skills `model` and `flows`
could not say, or guessed (`specs/plan3/B2.md`, `specs/plan3/C1.md`). Astra and a Fable
architect each judged its eight rows apart (`research/plan3/c2/`, out of Git). They agreed on
six; the owner took the joined column on 2026-11-25.

**After it** a step of a flow names the files where the code does it, the check warns when
one is gone, and the page shows them. Six conventions that runs guessed are sentences of the
guide, which every skill gets with the format.

## `source` on a step

    - id: checks
      does: component-checkout
      name: Checks the order and works out the price
      source: [services/orders/checkout.go]

| What | It does |
| --- | --- |
| The key | The paths of one to three files where the code does the step, by the rules of a connection's `source`. It may be left out, and stands on a step with no `does` too |
| The check | A path that is gone is the warning `source-gone`, a folder the warning `source-folder`, each said by the step's address: "`source` of step `flow-x#checks` names …" |
| The page | The bar of the current step shows a line "Source" with the paths. Under a change it is compared with today's, as a step's other keys are |
| The skill `flows` | Rule 1: the file that showed a step goes in its `source`. Step 5 holds each step by it, in place of a list written into the session |

- **Why not the connection's own `source`**: in the eleven flows of C1 at least 86 of 124 steps
  on a connection name a file that their connection's `source` lacks. The count is rough: it
  matches file names from the runs' own messages.
- **Its limit**: a path can be right and the step wrong. It says where to look, to a reader,
  to a mend after the code moved, and to whoever builds an applied change.
- **Where it is left out**: on a step that a change writes anew, which has no file yet; and
  in a model with no code, as the two of stage D are.

The skill `model` says the seventh in its rule 3, within its 120 lines.

## Why an inferred connection gets no key

Astra would give a connection `inferred`, a list of files drawn dashed, and named its own
doubt: if every link that can be defended already counts for `source`, the key is not needed.
Fable looked at the 41 connections of B's last round whose file shows one end only. By its
count 4 are topics that a part with no code here writes, shown by the reader's file: right,
and only the guide's letter was against them. 35 are code or settings that several apps load:
there a mark would be the way round the rule that a connection needs a file. So the sentence
takes in the four, and the rule stays whole. **To look at again**: after one round of `model`
with the sentence, if more than 5 sources in 100 still show one end only.

## Refused

A key that names a copy of an app; a `name` that every step must have; a key for a backend
that is chosen or for one part that starts another; `source` on the flow in place of the
step; a key for a fork or for a loop. Each would be written and never read by the check, the
page or a skill, or says what a word of the name says already.

## One run, and what is not shown

One run of `flows` with the key and the sentences, on Syncthing's first journey: 12 of 13
steps bear a `source`, the reply alone has none; their 14 paths are files of the tree that
the session saw; the id is a doing; the steps say "each" and which device acts; the check is
clean, and the page shows the line. The names now begin with the copy, not with the verb.

- **Whether a path keeps a run honest.** A run can name a file it never opened. The arm
  without the skill's text was not run again with the key.
- **One run says little of six sentences**, and nothing of a second way in or of a name left
  out. **Row 7's sentence** has met no run of `model`.

## Tests

Five more, 275 in all: the key read, and refused with a path that climbs out; `source-gone`
and `source-folder` on a step, by its address, and no warning for a step with none; the step
as the page reads it; under a change, compared with today's; the guide's new words. A rename
leaves a path alone. The plugin's test holds both skills at 120 lines at most.
